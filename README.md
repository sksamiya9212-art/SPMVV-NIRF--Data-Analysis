**---- Exploratory Data Analysis of NIRF Ranking Parameters of SPMVV ----**



\-- **Project Overview**



This project performs an exploratory analysis of NIRF ranking parameters of Sri Padmavathi Mahila Visvavidyalayam (SPMVV) to understand institutional performance across academics, placements, faculty, research, patents, and fellowships.



The project combines Python, Excel, and Power BI to clean, analyze, visualize, and present institutional data through meaningful KPIs and an interactive dashboard.



\-- **Tools Used**



* &#x20;Python
* &#x20;Pandas
* &#x20;Matplotlib
* &#x20;Excel
* &#x20;Power BI



\-- **Key Analysis**



* &#x20;Student placement trends
* &#x20;Faculty analysis
* &#x20;Research and publication analysis
* &#x20;Patent analysis
* &#x20;Fellowship analysis
* &#x20;Institutional performance indicators



\-- **Dashboard**



An interactive Power BI dashboard was created to present key institutional performance indicators and trends.



The dashboard enables users to explore the data through KPIs, charts, filters, and department-level analysis.
